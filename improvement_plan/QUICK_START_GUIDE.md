## P0.5 인테이크 인터뷰에서 확정되는 내용

보고서 작성에 앞서 AI가 아래 항목을 질문합니다. 한 번에 하나씩, 선택지 제시 방식으로 진행합니다.

| 확정 항목 | 질문 내용 | 왜 미리 확정하는가 |
|----------|----------|-----------------|
| 목차 방식 | 프레임워크 기준 / 테마 중심 / 기존 목차 참조 중 선택 | 목차 방식에 따라 섹션 구조가 완전히 달라짐 |
| 포함/제외 섹션 | 정보보안 포함 여부, 협력사 내용 여부 등 | 누락 섹션 발견 시 재작업 비용이 큼 |
| 서술 스타일 | 체계·정책 설명 위주 vs 활동·성과 중심 vs 섹션마다 다름 | 자료 유형에 따라 서술 방향이 다름 |
| 문체·회사명 규칙 | 종결어미(-입니다체/-합니다체), 회사명 약칭 규칙 | 전체 초안의 문체 일관성 보장 |
| 레퍼런스 보고서 | 이전 연도 보고서 또는 벤치마크 보고서 파일 경로 | 스타일 참조용 |
| 정량 데이터 입수 상태 | 대부분 확보 / 일부만 확보 / 거의 없음 중 선택 | 초안 완성도 사전 예측 가능 |
| 핵심 성과·수상 내역 | 반드시 보고서에 포함해야 하는 항목 | 빠뜨리지 않고 초안에 직접 반영 |

인터뷰 결과는 `00_definition/intake_manifest.json`에 저장됩니다.

## P1 자료 투입 시 자동으로 받는 정보

### HWP 등 처리 불가 파일 즉시 고지

자료를 넣는 즉시 변환 불가 파일을 탐지하고 아래 형식으로 알려드립니다.

```
처리 불가 파일 발견 — 확인 필요

| 파일 | 형식 | 추정 데이터 | 영향 가능 섹션 | 우선도 |
|------|------|------------|---------------|--------|
| 산업안전보건위원회_1Q.hwp | HWP | 재해율, 사고 건수 | 안전보건 > 재해현황 | 높음 |

권장 조치:
1. HWP 파일을 .md 파일로 수동 변환하여 다시 넣어주세요
2. 또는 [추후 기재]로 처리하고 나중에 데이터를 직접 입력하셔도 됩니다
```

### 데이터 갭 리포트 자동 생성

모든 파일 변환이 완료되면 섹션별 데이터 충족도를 자동으로 계산합니다.

```
데이터 갭 리포트

전체 19개 섹션 중:
- 데이터 충족 (5개): CEO 메시지, 지속가능경영 전략 ...
- 부분 확보 (8개): 고용, 복리후생 ...
- 데이터 부족 (6개): 재해 및 사고 현황, 임직원 현황 ...

즉시 확보 권장 데이터:
1. 재해율(LTIR/TRIR) → 안전관리팀 → 영향 섹션: 안전보건
2. 성별·고용형태별 임직원 수 → 인사팀 → 영향 섹션: 고용
```

상세 내용은 `02_file_registry/data_gap_report.json`에 저장됩니다.

## P1.5 목차 논의

인테이크 인터뷰 결과와 데이터 갭 리포트를 기반으로 목차 초안을 자동 생성합니다.

1. AI가 목차 초안을 생성하여 컨설턴트에게 제시
2. 컨설턴트가 검토 후 수정 요청 또는 승인
3. 승인된 목차는 `05_planning/toc_draft.json`에 저장

**이 단계의 컨설턴트 승인 없이는 P2(블루프린트) 진행이 불가합니다.**

수정 요청 방법: "3번 섹션 제목을 '안전보건체계 고도화'로 바꿔주세요", "4번과 5번 순서를 바꿔주세요" 등 자연어로 말씀하시면 됩니다.

## 컨설턴트가 준비하면 좋은 자료 (선택사항)

| 자료 | 용도 | 필수여부 |
|------|------|---------|
| 이전 연도 보고서 | 스타일 참조 | 선택 |
| 이중중대성 평가 결과 | 섹션 깊이 배분 | 선택 |
| 임직원 통계 데이터 | 인적자원 섹션 수치 | 나중에 기재 가능 |
| 안전 재해율 데이터 | 안전보건 섹션 수치 | 나중에 기재 가능 |
| 2024년 활동 보고서 | 사례 중심 서술 | 없으면 체계 설명으로 자동 전환 |

## 데이터가 없을 때 처리 방식

- **정량 수치 없음** → `[추후 기재]` 표시로 위치를 잡아두고, 나중에 채울 수 있음
- **활동 사례 없음** → AI가 컨설턴트에게 확인 요청. ① 체계·정책 서술로 전환하거나 ② 추가 자료 투입 후 재작성 중 선택
- **HWP 변환 불가** → 즉시 고지 + 영향 받는 섹션 표시. 수동 변환 또는 [추후 기재] 처리 중 선택
